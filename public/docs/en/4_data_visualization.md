# Dynamic Data Visualization

**AmoxSQL** transcends the plain text nature of traditional SQL IDEs by embedding an iterative and reactive charting engine called **`DataVisualizer.jsx`**. This supermassive module (the largest file in the Frontend architecture) provides functionality usually found in comprehensive Business Intelligence tools.

---

## 1. Charting Engine Integration (Recharts)

Instead of using raw Canvas or complex raw D3, AmoxSQL wraps the **Recharts** library. Recharts allows declarative composition in React, which means that as data or configurations (like window size or theme color) change, SVG elements transition smoothly thanks to React's algorithmic reconciliation engine.

### Supported Types
The options menu mutates the main React state iterating through specialized components:
1.  **BarChart (Vertical and Horizontal):** Configurable to show Stacked Bars or Side by Side.
2.  **LineChart & AreaChart:** Preferred for time series. Supports stepped mode (`step`), monocubes (`monotone`), or rigid linears.
3.  **PieChart / Donut:** Parametric sector diagrams.
4.  **ScatterChart:** Crucial for identifying outliers or the distribution of X vs Y data clusters.

## 2. Pivot & Dynamic Numeric Grouping

Often, the query generated by DuckDB might be a `SELECT *` of tens of thousands of granular logs. The user does not need to return to the SQL code and type a long `GROUP BY` block and complex mathematical functions to see it reflected in a chart.

The AmoxSQL *Visualizer* has a JS aggregation engine:
*   If the "Group X Axis" toggle is enabled, the interface groups the keys of the `xAxisKey` state.
*   The user can select a dynamic mathematical algorithm from the UI: `Sum`, `Average`, `Min`, or `Max`.
*   For data of a temporal nature (Time-Series Dates), there is a special interactive menu that "Pivots" the time series to collapse the data by Day, Month, or Year without touching the DuckDB database again, facilitating the identification of monthly anomalies on the fly.

## 3. Reference Indicators (Storytelling)

For true "Storytelling" modeling, analysts need to visually annotate where critical events occurred in the life of business data.

*   **Reference Lines:** Mathematically integrated. An operator can draw a red line at `Y = 10,000` labeled "Q4 Sales Goal" to demonstrate at a glance whether a business expectation was exceeded.
*   **Reference Areas:** Allows illuminating the background (background fill with configurable opacity) of a temporal space on the graph, such as coloring the entire month of "December" in a faint color to indicate "Year-End Promotions".

## 4. Numeric and Aesthetic Persistence

### Smart Numeric Formatting
The user can change the representation on their axes (Y and Tooltips):
*   **Raw:** Javascript Literal `(1000000)`.
*   **Compact:** Dynamic scaling to the American standard `(1M, 1.5K)`.
*   **Currency:** Adds the dollar prefix or parameterized currency.
*   **Percentage:** Intercepts decimal Tooltips multiplying by a hundred base.

### Accessibility: Panels and Default Views
The current user (v1.6.0) has explicit controls for overloaded reading through the `SettingsModal`.
*   **Independent Font-Size Controls:** The size of cells and rows in Results can be varied between 11px to 16px to increase density or relax scrutiny fatigue.
*   **Default View (Custom View):** A saved *LocalStorage* preference to force AmoxSQL to always open in the "Chart" tab (Ideal for Managers) or in "Table" or "Profile" if occupied by an Engineer.

### `*.amoxvis` Format
Building a perfect chart—with labeled axes, custom colors from its palette selector, 45-degree rotations for long headers, adjusted margins, and legends—takes time.

To prevent the loss of this work, the giant JSON customization state in the Visualizer Component's memory is dumped via the explorer API to an `.amoxvis` file within the project folder. These files travel directly with Git code versioning alongside `*.sql` files.

### Ultra-Resolution PNG Export
Using the `html2canvas` technique injected alongside pixel density multipliers (parametric Device Pixel Ratio), the explorer does not just take a dirty screen "Screenshot", but imperatively clones the rendered SVG Node in memory, digitally magnifies it (up to a 4x retina scale modifier), disables IDE borders, and prints the immaculate chart in PNG ready to integrate into executive presentations or institutional slides.
